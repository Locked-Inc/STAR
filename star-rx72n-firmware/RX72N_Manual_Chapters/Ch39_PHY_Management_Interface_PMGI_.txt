39.3

39. PHY Management Interface (PMGI)

Operation

The PMGI supports MII management frame formats in compliance with IEEE 802.3, and handles access to the registers
of PHY LSI chips via two serial interface circuits.

39.3.1

Format of MII Management Frames

Table 39.3 lists the data format of management frames, Figure 39.2 shows the format in the case of reading, and Figure
39.3 shows the format in the case of writing.
An MII management frame consists of a 32-bit preamble (PRE), 2-bit start field (ST), 2-bit operation code (OP)
indicating reading or writing, 5-bit PHY address (PHYAD) and PHY register address (REGAD), 2-bit turnaround (TA)
field, 16 bits of data (DATA), and a 1-bit idle condition (IDLE).
Setting the PSMR.PSME bit to 1 triggers the output of an MII management frame. The settings of the PSMR.PDA[4:0]
bits and the PSMR.PRA[4:0] bits correspond to the PHY address and the PHY register address, respectively. In the case
of reading, the value set in the PSMR.PRD[15:0] bits is written to the register of PHY-LSI. In the case of writing, the
value to be written is set in the PSMR.PRD[15:0] bits.
The PMGCR.PSMDP bit can select if a preamble field is to be included. Setting the PMGCR.PSMDP bit to 1 triggers the
start of sending from the start field.

39.3.5

39. PHY Management Interface (PMGI)

Interrupts

When transfer of an MII management frame is completed, the PSMR.PSME bit automatically becomes 0, and an accesscompleted interrupt request is generated.
Each PMGI (PMGI0I and PMGI1I) has its own access completed interrupt circuit, and different vector addresses are
allocated to the two. When an access completed interrupt is generated, the corresponding interrupt request is output.
When the interrupt request is to generate a CPU interrupt, the order of priority of the two signals can be changed by
setting the interrupt controller. For details, refer to section 15, Interrupt Controller (ICUD).

Usage Notes
Settings of the Module Stop Function

Each PMGI can be placed in or released from the module stop state by setting module stop control register B
(MSTPCRB). The initial setting is for the module stop state. Release from the module stop state enables access to the
registers of the PMGI. For details of module stop control register B, refer to section 11, Low Power Consumption.

Do not set the PMGCR.PSMHT[2:0] bits to a value greater than that of the PSMCS[5:0] bits.
