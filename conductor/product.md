# Product Guide

## Initial Concept
**STAR (Sensor and Actuator Abstraction Runtime)** is a distributed robotics platform designed as a capstone engineering project for the Texas A&M University (TAMU) Electronic Systems Engineering Technology (ESET) program. The project aims for completion by the Spring 2026 semester.

## Target Users
- **Robotics Researchers & Students:** Providing a modular platform for experimenting with algorithms, control systems, and sensor fusion.
- **Hobbyists & Makers:** Offering a robust, customizable foundation for building advanced robotic applications.
- **Academic Institutions:** Serving as an educational tool for embedded systems and robotics middleware.

## Core Value Proposition
STAR bridges the gap between low-level hardware control and high-level robotics software. By abstracting complex sensor and actuator interactions into a unified runtime, it enables users to focus on developing intelligent behaviors. The platform combines custom PCB hardware with industry-standard software stacks like ROS2 and embedded Linux.

## Key Features
- **Distributed Architecture:** Raspberry Pi 5 for high-level processing and Renesas RX72N for real-time motor control.
- **Custom Embedded OS:** Tailored Buildroot Linux distribution optimized for performance.
- **Robust Communication:** Protocol Buffers over SPI for reliable inter-processor data exchange.
- **Advanced Control:** Precise closed-loop motor control with PID algorithms tuned via MATLAB.
- **Modern Connectivity:** ROS2 Jazzy integration and a Go-based gateway for external interfacing.

## Success Metrics
- **Delivery:** Fully functional prototype by Spring 2026.
- **Performance:** Stable real-time control loops and reliable inter-device communication.
- **Academic Success:** Fulfillment of all TAMU ESET capstone project requirements.
