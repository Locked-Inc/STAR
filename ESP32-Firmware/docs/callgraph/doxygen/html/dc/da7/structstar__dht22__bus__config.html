Detailed Description

DHT22 bus configuration structure (part of star_bus_config_t).

Manages a DHT22/DHT11/AM2301 temperature and humidity sensor using a proprietary single-wire protocol. This protocol is NOT compatible with Dallas 1-Wire.

Protocol characteristics:

  • Single bidirectional data line
  • Host-initiated communication
  • 40-bit data format (16-bit humidity + 16-bit temp + 8-bit checksum)
  • Minimum 2 seconds between readings
