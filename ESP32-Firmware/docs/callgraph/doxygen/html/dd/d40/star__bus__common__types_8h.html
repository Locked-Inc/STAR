typedef esp_err_t(* pin_registration_function_t) (gpio_num_t pin_num, const char *bus_name, const char *pin_usage, void *user_ctx)

Callback function type for pin registration.

Parameters
[in]pin_numThe GPIO pin number being registered.
[in]bus_nameThe name of the bus configuration using this pin.
[in]pin_usageA descriptive string of how the pin is used (e.g., "I2C SDA", "SPI COPI").
[in]user_ctxUser context pointer provided to star_bus_manager_register_all_pins.
Returns
esp_err_t Should return ESP_OK on successful registration, or an error code otherwise.
