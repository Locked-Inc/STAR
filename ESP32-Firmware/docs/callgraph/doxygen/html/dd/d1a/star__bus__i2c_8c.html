Helper: Execute I2C command with retry logic.

Helper: Execute I2C command.

Wraps i2c_master_cmd_begin() with automatic retry for transient errors. Distinguishes between transient errors (timeout, general failure) that should be retried and permanent errors (invalid parameters) that shouldn't.

Parameters
[in]configPointer to I2C bus configuration
[in]portI2C port number
[in]cmdI2C command handle
[in]operation_nameName of operation for logging
Returns
esp_err_t Final result after retries

Note: Retry logic has been removed as error handling is now done at the manager level through the injected error_iface. This function performs a single attempt.
