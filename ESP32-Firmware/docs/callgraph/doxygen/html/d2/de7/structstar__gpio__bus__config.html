Detailed Description

GPIO bus configuration structure (part of star_bus_config_t).

Manages a collection of GPIO pins as a logical "bus" for device control. Useful for sensors like HC-SR04 that use GPIO pins directly rather than a traditional communication bus (I2C/SPI).
