This header provides type-safe structured constants for servo control, replacing the legacy macro-based approach with proper encapsulation.

◆ star_servo_get_constants()

const star_servo_constants_t * star_servo_get_constants ( void )

Get the default servo constants.

Returns a pointer to the statically allocated default servo constants. These values are suitable for standard hobby servos.

Returns
Pointer to immutable servo constants structure
Note
The returned pointer references static const data and should not be freed
Thread-safe: returns pointer to read-only data

Example usage:

const star_servo_constants_t* constants = star_servo_get_constants();
printf("Min pulse: %u us\n", constants->pulse.min_us);
printf("Max angle: %u degrees\n", constants->angle.max);
printf("PCA9685 frequency: %u Hz\n", constants->pca9685.freq_hz);
