◆ star_servo_angle_to_count()

uint16_t star_servo_angle_to_count ( uint8_t angle)

Calculate PCA9685 count value from angle (0-180 degrees).

Uses standard servo mapping:

  • 0° = 1.0ms pulse = ~205 counts
  • 90° = 1.5ms pulse = ~307 counts
  • 180° = 2.0ms pulse = ~410 counts
Parameters
[in]angleServo angle in degrees (0-180)
Returns
PCA9685 count value (0-4095)
Note
This is a pure calculation function with no side effects
Angles outside 0-180 are clamped to valid range

◆ star_servo_pulse_to_count()

uint16_t star_servo_pulse_to_count ( uint16_t pulse_us)

Calculate PCA9685 count value from pulse width in microseconds.

For PCA9685 at 50Hz (20ms period): count = (pulse_us * 4096) / 20000

Parameters
[in]pulse_usPulse width in microseconds (typically 1000-2000)
Returns
PCA9685 count value (0-4095)
Note
This is a pure calculation function with no side effects
Pulse widths are clamped to prevent overflow
