158/* --- SPI Pin Naming: COPI/CIPO (OSHWA Standard) --- */
159/* This component uses OSHWA (Open Source Hardware Association) standard SPI terminology:
160 * - COPI (Controller Out, Peripheral In): Data line where the controller sends data to the peripheral
161 * - CIPO (Controller In, Peripheral Out): Data line where the controller receives data from the peripheral
162 *
163 * This modern terminology replaces the outdated master/slave language:
164 * - COPI replaces MOSI (Master Out, Slave In)
165 * - CIPO replaces MISO (Master In, Slave Out)
166 *
167 * Note: The ESP-IDF SPI slave driver still uses mosi_io_num/miso_io_num internally, which we map to COPI/CIPO.
168 */
