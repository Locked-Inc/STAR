◆ star_sensor_mpu6050_init()

esp_err_t star_sensor_mpu6050_init ( mpu6050_handle_t * handle,
star_bus_manager_t * manager,
const char * bus_name,
star_error_interface_t * error_iface,
const mpu6050_config_t * config )

Initialize MPU6050 IMU sensor.

Performs device detection, configuration, and initialization. Thread-safe: Creates an internal mutex for protecting handle state.

Parameters
[out]handlePointer to handle structure (must be allocated by caller)
[in]managerPointer to initialized bus manager
[in]bus_nameName of I2C bus configured for this device
[in]error_ifaceError interface for error handling (NULL = create default internally)
[in]configDevice configuration
Returns
ESP_OK on success, error code otherwise
Note
The handle must be deinitialized with star_sensor_mpu6050_deinit() when done
If error_iface is NULL, a default error handler will be created internally
All operations after init are protected by mutex for thread safety
