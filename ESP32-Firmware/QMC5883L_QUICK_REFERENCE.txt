DEVICE IDENTIFICATION
================================================================================
Part Number:           QMC5883L (by Qst Electronics)
I2C Address:           0x0D (7-bit), 0x1A (8-bit write), 0x1B (8-bit read)
Chip ID Register:      0x0D (reads 0xFF)
Supply Voltage:        2.4V to 3.6V (typically 3.3V for ESP32)
Operating Temp:        -30°C to +85°C
Interface:             I2C (SMBus compatible)

DATA FORMAT (CRITICAL)
================================================================================
Byte Order:            LITTLE-ENDIAN (LSB first) - OPPOSITE of HMC5883L
Data Type:             16-bit signed integer (two's complement)
Range:                 -32768 to +32767
Conversion:            value = (MSB << 8) | LSB (then cast to int16_t)

IMPORTANT: HMC5883L uses BIG-ENDIAN. Many cheap modules labeled HMC5883L
          actually contain QMC5883L with OPPOSITE byte order!

REGISTER MAP - OUTPUT REGISTERS
================================================================================
Address | Name         | R/W | Default | Description
--------|--------------|-----|---------|----------------------------------
0x00    | X_OUT_LSB   | R   | 0x00    | X-axis data (low byte)
0x01    | X_OUT_MSB   | R   | 0x00    | X-axis data (high byte, sign bit)
0x02    | Y_OUT_LSB   | R   | 0x00    | Y-axis data (low byte)
0x03    | Y_OUT_MSB   | R   | 0x00    | Y-axis data (high byte, sign bit)
0x04    | Z_OUT_LSB   | R   | 0x00    | Z-axis data (low byte)
0x05    | Z_OUT_MSB   | R   | 0x00    | Z-axis data (high byte, sign bit)
0x06    | STATUS      | R   | 0x00    | [2:DRDY_EV, 1:OVL, 0:DRDY]
0x07    | TEMP_LSB    | R   | 0x00    | Temperature (optional)
0x08    | TEMP_MSB    | R   | 0x00    | Temperature (optional)

REGISTER MAP - CONFIGURATION REGISTERS
================================================================================
Address | Name        | R/W | Default | Bit Positions
--------|-------------|-----|---------|----------------------------------
0x09    | CONTROL_1   | R/W | 0x1D    | [7:6 OSR, 5:4 RNG, 3:2 ODR, 1:0 MODE]
0x0A    | CONTROL_2   | R/W | 0x00    | [7 SOFT_RST, 6 ROL_PNT, 0 INT_ENB]
0x0B    | SET_RESET   | R/W | 0x01    | [7:0 FBR - calibration period]
0x0D    | CHIP_ID     | R   | 0xFF    | Device identification (always 0xFF)

CONTROL REGISTER 1 (0x09) - BIT FIELDS
================================================================================
Bits [1:0] - MODE (Operation Mode)
  00 = Standby (low power, sensor off)
  01 = Continuous measurement
  10 = Single measurement (returns to standby after)
  11 = Reserved (DO NOT USE)

Bits [3:2] - ODR (Output Data Rate)
  00 = 10 Hz
  01 = 50 Hz
  10 = 100 Hz
  11 = 200 Hz

Bits [5:4] - RNG (Magnetic Field Range)
  00 = ±2 Gauss (1 mG/LSB) - MAX SENSITIVITY
  01 = ±8 Gauss (4 mG/LSB) - WIDER RANGE
  10-11 = Undefined

Bits [7:6] - OSR (Over-Sample Rate)
  00 = 512 (minimum noise, longest measurement)
  01 = 256
  10 = 128
  11 = 64 (fastest response, highest noise)

CONTROL REGISTER 2 (0x0A) - BIT FIELDS
================================================================================
Bit [0] - INT_ENB (Interrupt Enable)
  0 = DRDY pin disabled
  1 = DRDY pin enabled (active LOW pulse on data ready)

Bit [6] - ROL_PNT (Register Pointer Roll-over)
  0 = Pointer does not roll over
  1 = Pointer auto-increments 0x00→0x06→0x00 (RECOMMENDED)

Bit [7] - SOFT_RST (Software Reset)
  Write 1 to reset device (self-clearing)
  After reset, device returns to default state

STATUS REGISTER (0x06) - BIT FIELDS
================================================================================
Bit [0] - DRDY (Data Ready)
  0 = No new data available
  1 = New measurement data available

Bit [1] - OVL (Overflow)
  0 = Normal operation
  1 = Magnetic field exceeds measurement range - DISCARD DATA

Bit [2] - DRDY_EV (Data Ready Event)
  Capture event indicator

Bits [7:3] - Reserved (always read as 0)

I2C PROTOCOL
================================================================================
Speed:                 100 kHz (standard) or 400 kHz (fast, recommended)
Address Format:        7-bit (0x0D for QMC5883L)
Write Sequence:        START | ADDR+W | REG_ADDR | DATA | STOP
Read Sequence:         START | ADDR+W | REG_ADDR | RESTART | ADDR+R | DATA* | STOP
Repeated START:        YES (required between write and read phases)
Pointer Auto-Roll:     YES (enable via register 0x0A[6] for efficient reads)
Timeout:               1000 ms recommended per transaction

SENSITIVITY & CONVERSION
================================================================================
Field Range | LSB Size | Sensitivity | Example Conversion
─────────────────────────────────────────────────────────
±2 Gauss    | 1 mG     | 1000 LSB/G  | value_gauss = raw / 1000.0
±8 Gauss    | 4 mG     | 250 LSB/G   | value_gauss = raw / 250.0

Safe Conversion Code:
  float sensitivity = (range == 0) ? 0.001f : 0.004f;  // Gauss per LSB
  float gauss = raw * sensitivity;

MEASUREMENT PROCEDURES
================================================================================

CONTINUOUS MODE:
1. Set MODE=01, desired ODR, range, OSR in register 0x09
2. Poll DRDY bit (status 0x06[0]) or use DRDY interrupt
3. When DRDY=1, read 6-7 bytes from 0x00
4. Convert bytes to int16_t values
5. Check for overflow (status 0x06[1])
6. Repeat from step 2

SINGLE-SHOT MODE:
1. Set MODE=10 in register 0x09
2. Device measures once, returns to standby
3. Poll DRDY bit or wait for interrupt
4. Read 6-7 bytes from 0x00
5. To take next measurement, write MODE=10 again

CALIBRATION PROCEDURE (FIGURE-8 METHOD)
================================================================================
1. Put device in continuous mode, 10Hz, ±2G range
2. Hold device at arm's length
3. Rotate device in figure-8 pattern in all three planes
4. Collect min/max values for X, Y, Z over 60-120 seconds
5. Calculate offsets: offset_x = (x_max + x_min) / 2
6. Calculate scales: scale_x = max_range / (x_max - x_min)
7. Store calibration parameters
8. On read: calibrated_value = (raw - offset) * scale

  CONTROL_2 = 0x40  (enable pointer roll-over)
  SET_RESET = 0x01

Gaming/Real-Time:

  CONTROL_2 = 0x40
  SET_RESET = 0x01

  CONTROL_1 = 0x02  (MODE=10, single-shot)
  CONTROL_2 = 0x40
  SET_RESET = 0x01

ERROR CODES & STATUS
================================================================================
Status: DRDY=0          → No new data, sensor not updating
Status: OVL=1           → OVERFLOW - discard measurement
Register read fails     → I2C bus issue or wrong address (0x0D)
Chip ID != 0xFF         → Wrong device (might be HMC5883L at 0x1E)
Constant readings       → Sensor frozen, try soft reset
Noisy readings          → EMI interference, check power/shielding

COMMON MISTAKES
================================================================================
1. ❌ Wrong byte order reconstruction (using big-endian for little-endian data)
   ✓  Always: value = (int16_t)((msb << 8) | lsb)

2. ❌ Using HMC5883L code without modification
   ✓  Check I2C address first (0x0D = QMC5883L, 0x1E = HMC5883L)

3. ❌ Not checking overflow flag in high magnetic fields
   ✓  Always check status 0x06[1] before using measurement

4. ❌ Polling DRDY without timeout
   ✓  Always set 1000ms timeout to prevent deadlock

5. ❌ Writing to register 0x0C (reserved)
   ✓  Only write to 0x09, 0x0A, 0x0B

6. ❌ Calling I2C functions from ISR context
   ✓  Use queue/semaphore to notify task from ISR

7. ❌ Not validating calibration results
   ✓  Check scale factors are between 0.5 and 2.0

8. ❌ Using ±2G range in strong magnetic field environments
   ✓  Use ±8G range for robustness (lower sensitivity but wider range)

SAFETY CHECKLIST
================================================================================
- [ ] Verify chip ID (0x0D register) returns 0xFF before operation
- [ ] All register writes validated (only to 0x09, 0x0A, 0x0B)
- [ ] All I2C reads/writes have timeout enforcement (1000ms)
- [ ] Overflow flag checked on every read
- [ ] Data consistency check (detect stuck sensor)
- [ ] Proper little-endian conversion with int16_t cast
- [ ] All buffers sized correctly (minimum 7 bytes for full read)
- [ ] Thread-safety (mutexes) if accessing from multiple tasks
- [ ] ISR safety (never call I2C in ISR, use queue notification)
- [ ] Soft reset recovery tested
- [ ] Calibration procedure documented
