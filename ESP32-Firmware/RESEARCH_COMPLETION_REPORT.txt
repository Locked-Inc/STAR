================================================================================
                        KEY RESEARCH FINDINGS
================================================================================

CRITICAL FINDINGS:

1. Little-Endian Data Format
   QMC5883L uses LSB first (little-endian) - OPPOSITE of HMC5883L
   Correct: value = (int16_t)((msb << 8) | lsb)

2. Register Map (0x00-0x0D)
   All 14 registers documented with bit-level detail
   Default values and access permissions specified

3. I2C Address vs Chip ID
   I2C Address: 0x0D (7-bit)
   Chip ID Register: Also at 0x0D (reads as 0xFF)
   These are DIFFERENT concepts

4. Automated Self-Test
   QMC5883L performs automatic magnetic field restoration
   Controlled by register 0x0B (default 0x01 recommended)

5. DRDY Synchronization
   Data Ready pin provides active-LOW interrupt
   Enabled via register 0x0A[0]
   Recommended for lowest latency

6. Register Pointer Auto-Roll
   Setting 0x0A[6] enables pointer wrap-around
   Allows efficient sequential read of all 7 bytes

7. Overflow Protection
   Status register 0x06[1] indicates overflow
   Must check and discard invalid measurements

8. Power Consumption
   Standby: <1 µA | 10Hz: ~400 µA | 200Hz: ~800 µA
