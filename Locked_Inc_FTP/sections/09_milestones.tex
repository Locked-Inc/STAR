\subsection{Milestone Overview}

The milestones outline the project's key development checkpoints and provides a structured method for tracking team progress throughout the schedule.

\subsection{Milestone Acceptance Criteria}

Each milestone has specific acceptance criteria that must be met. These criteria follow SMART principles: Specific, Measurable, Achievable, Relevant, and Time-Bound.

\subsubsection{M1: PDR (October 29, 2025)}

\begin{itemize}
    \item PDR presentation delivered
    \item All functional and non-functional requirements documented
    \item Project scope and timeline approved
    \item Sponsor feedback incorporated into project plan
\end{itemize}

\subsubsection{M2: Research Phase Complete (October 31, 2025)}

\begin{itemize}
    \item All requirements documented and approved by sponsor
    \item Technology selection justified with trade-off analysis
    \item Risk assessment completed with mitigation strategies
    \item Competitive analysis finalized
\end{itemize}

\subsubsection{M3: Software Demo (December 3, 2025)}

\begin{itemize}
    \item Core software functionality demonstrated to sponsor
    \item Basic SLAM algorithm validated with test data
    \item Software architecture documented
\end{itemize}

\subsubsection{M4: Design Review (February 28, 2026)}

\begin{itemize}
    \item All design documents reviewed and approved
    \item No critical design issues outstanding
    \item Bill of materials finalized and procurement initiated
    \item Hardware-software interface specifications complete
\end{itemize}

\subsubsection{M5: Hardware Integration Complete (March 31, 2026)}

\begin{itemize}
    \item All components procured and received
    \item Physical robot assembly completed
    \item Initial power-on successful with basic diagnostics
    \item Sensor integration verified with test readings
\end{itemize}

\subsubsection{M6: Software Integration Complete (April 15, 2026)}

\begin{itemize}
    \item All software modules integrated on physical hardware
    \item Basic navigation functionality verified
    \item Communication between all subsystems operational
    \item Ready for system-level testing
\end{itemize}

\subsubsection{M7: System Testing Complete (May 1, 2026)}

\begin{itemize}
    \item All test cases executed per test plan
    \item Critical defects resolved with verification
    \item Performance requirements verified against specifications
    \item Test reports documented and reviewed
\end{itemize}

\subsubsection{M8: Final Demonstration (May 8, 2026)}

\begin{itemize}
    \item System demonstrates all required functionality
    \item Autonomous mapping of 10 m × 10 m area completed
    \item Sponsor accepts deliverable and signs off
    \item All documentation complete and delivered
\end{itemize}
