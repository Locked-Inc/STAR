\subsection{Resource Overview}

    This section documents team resource allocation across all WBS
        activities.The six -
    member team operates approximately 8 -
    10 hours per member weekly during the academic semester,
    with adjusted availability during exam periods
        .Resource planning ensures balanced workload distribution while aligning
            individual expertise with task requirements.

\subsection{Resource Allocation Matrix(RAM)}

    The RAM defines team member responsibilities using the RACI
        model \parencite{pmi_raci} :

\begin {
  itemize
}
\item \textbf{R} - Responsible : Does the work
    \item \textbf{A} - Accountable : Ultimately answerable(one per activity)
    \item \textbf{C} - Consulted : Provides input
    \item \textbf{I} - Informed : Kept updated
\end {
  itemize
}

\subsection { Resource Constraints }

\begin { itemize }
\item Team members available 8 - 10 hours per week during academic semester
    \item Reduced availability during exam periods(midterms, finals)
    \item Reduced productivity during university
    breaks(Thanksgiving, Winter, Spring Break)
    \item Critical skills requiring coverage : ROS 2(JB, JH),
    PCB design(BS), mechanical CAD(MN)
    \item Hardware lab access available 24 / 7 during semester
\end {
  itemize
}

\subsection{Resource Leveling}

Resource conflicts are resolved by :

\begin {
  enumerate
}
\item Adjusting activity timing within available float
    \item Reassigning activities to available team members with appropriate
        skills
    \item Splitting activities across multiple team members where feasible
    \item Prioritizing critical path activities over non -
    critical work
\end {
  enumerate
}
