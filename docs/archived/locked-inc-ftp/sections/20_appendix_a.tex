\subsection {
  Acronyms and Definitions
}
\label{sec : acronyms}

The following acronyms and technical terms are used throughout this document :

\begin {
  enumerate
}
\item \label {
acr:
  STAR
}
\textbf{STAR}(Simultaneous Tracking and Robotics)
    : The autonomous indoor mapping robot developed by Locked Inc
          .as the subject of this senior design project.

    \item \label {
acr:
  SLAM
}
\textbf{SLAM}(Simultaneous Localization and Mapping)
    : An algorithmic technique that enables a robot to map its environment
      while simultaneously determining its own location within that environment.

    \item \label {
acr:
  ETID
} \textbf{ETID} (Department of Engineering Technology and Industrial Distribution): The academic department at Texas A\&M University responsible for the senior design program.

    \item \label{
acr:
  RPLiDAR
}
\textbf{RPLiDAR}(Robotic Perception LiDAR)
    : A compact and
      affordable
      2D LiDAR sensor used as a backup mapping sensor in the STAR Robot system.

    \item \label {
acr:
  PCB
}
\textbf{PCB}(Printed Circuit Board)
    : A board that mechanically supports
      and electrically connects electronic components
          using conductive pathways etched into copper layers.

    \item \label {
acr:
  LiDAR
}
\textbf{LiDAR}(Light Detection and Ranging)
    : A remote sensing technology that uses laser light to measure distances
      and create detailed 3D maps of environments.

    \item \label {
acr:
  ROS2
} \textbf{ROS2} (Robot Operating System 2): A flexible framework for writing robot software, providing libraries and tools for building robot applications.

    \item \label{
acr:
  CAD
}
\textbf{CAD}(Computer - Aided Design)
    : Software tools used to create digital designs
      and technical drawings of mechanical and
      electrical components.

    \item \label {
acr:
  MITLicense
}
\textbf{MIT License} : A permissive open -
                       source software license that allows free use,
    modification, and distribution with minimal restrictions,
    originating from the Massachusetts Institute of Technology.

    \item \label {
acr:
  GitHub
} \textbf{GitHub}: A web-based platform for version control and collaborative software development where project source code is publicly accessible and managed.

    \item \label{
acr:
  AMR
}
\textbf{AMR}(Autonomous Mobile Robot)
    : A mobile robot capable of understanding
      and navigating its environment without human intervention.

    \item \label {
acr:
  MIT
}
\textbf{MIT}(Massachusetts Institute of Technology)
    : A prestigious research university;
also refers to the MIT License, a permissive open - source software license.

    \item \label {
acr:
  RViz2
} \textbf{RViz2} (ROS Visualization 2): A 3D visualization tool for ROS 2 that displays sensor data, robot models, navigation paths, and generated maps in real-time during robot operation.

    \item \label{
acr:
  Nav2
}
\textbf{Nav2}(Navigation 2)
    : The ROS 2 navigation stack providing autonomous navigation
      capabilities including path planning,
      obstacle avoidance, and behavior trees.

\end {
  enumerate
}
