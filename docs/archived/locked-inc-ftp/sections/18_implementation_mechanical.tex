\subsection {
  Mechanical Preliminary Implementation
}

\sectionauthors { MN }

\subsubsection{Chassis Design}

    The mechanical design centers on a compact mobile platform capable of
        operating in confined or
    partially obstructed environments where first responders require quick
        mapping before entry.The chassis features a rigid,
    low - profile frame that houses the LiDAR, electronics, power system,
    and drivetrain in a protected configuration.

\textbf {
  Design Requirements:
}
\begin { itemize }
\item LiDAR mounted with unobstructed 270\textdegree {} field of view
    \item Raspberry Pi and electronics positioned centrally for balance
    \item Low center of gravity for stability during navigation
    \item Modular layout for maintenance and testing
\end{
  itemize
}

\textbf {
Materials:
}
\begin { itemize }
    \item \textbf{Base structure:} U-channel and sheet aluminum for rigidity
    \item \textbf{
      Upper structure:
    } 3D-printed PETG for lightweight, cost-effective fabrication, and machinability
\end{
      itemize
    }

\subsubsection{Drivetrain}

Multiple configurations were evaluated, including tracks, eight wheels, and six wheels with various sizes and placements. The four-wheel differential drive design was selected for its simplicity and adequate performance. Torque and RPM calculations confirmed the design meets requirements with a safety factor of three.

\textbf{
  Drive System Features:
}
\begin { itemize }
    \item Four-wheel independent drive for differential steering
    \item 3D-printed bevel gears transfer motor torque to wheel axes (cost savings)
    \item Wheel assemblies provide traction on tile, concrete, and other indoor surfaces
    \item Capable of traversing small obstacles
\end{
      itemize
    }

\subsubsection{Component Integration}

The internal layout is designed for easy reconfiguration:
\begin{
  itemize
}
    \item \textbf{Motor control subsystem:} ESP32 isolated to reduce electrical noise and manage thermal behavior
    \item \textbf{Battery housing:} Positioned at bottom center for low center of gravity; tray design enables easy battery replacement
    \item \textbf{Thermal management:} Ventilation pathways around Raspberry Pi for heat dissipation during sustained workloads
\end{
      itemize
    }
