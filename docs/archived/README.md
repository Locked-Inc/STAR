# Archived Documentation

## Purpose

This directory contains historical documentation from the ESET 419 class project phase. These documents serve as an archival record of:

- Original project planning and research
- Formal Test Procedure (FTP) documentation
- Initial design decisions and architecture
- Budget, timeline, and resource planning from the course project

## Important Notes

- **These documents reflect the state of the project during the ESET 419 course** and may not represent the current architecture or design decisions
- **Do not update or "fix" these documents** - they are intentionally preserved as historical artifacts
- **Technology choices documented here may have changed** (e.g., references to Kotlin, different architectures, etc.)
- For **current project documentation**, see `docs/star_documentation.tex` and the section files in `docs/sections/`
