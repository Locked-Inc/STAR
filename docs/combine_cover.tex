\section*{Section overview}
\addcontentsline{toc}{section}{Section overview}

\begin{description}
\item[Part I -- Engineering Reference] Comprehensive technical book:
hardware pinout, communication stack, NASA Power-of-10 rules, gateway
architecture, ROS2 integration, motor control loop, safety architecture,
test strategy, troubleshooting, glossary, compliance engine, operations
runbook, logging architecture (\texttt{docs/star\_documentation.pdf},
$\sim$241 pages).

\item[Part II -- Firmware Combined PDF] Every per-module Doxygen PDF for
the RX72N firmware: \texttt{src/} (application), \texttt{tests/} (host
unit-test suite), all 27 libraries under \texttt{libs/}, and all 11
bench-test applications. $\sim$16,000 pages, 128 MB
(\texttt{docs/STAR\_Firmware\_Combined.pdf}).

\item[Part III -- Gateway Combined PDF] Go gateway: \texttt{cmd/}
(virtual\_rx72n + cli tools), \texttt{internal/} (manager / controller /
service / transport / WebSocket), and \texttt{tests/} as syntax-highlighted
source listings (469 pages).

\item[Part IV -- ROS2 Combined PDF] All 9 STAR-owned ROS2 packages as
syntax-highlighted source listings: \texttt{star\_bringup},
\texttt{star\_compliance\_msgs}, \texttt{star\_gateway\_bridge},
\texttt{star\_perception}, \texttt{star\_safety\_monitor},
\texttt{star\_simple\_bridge}, \texttt{star\_simulation},
\texttt{star\_spi\_bridge}, \texttt{star\_supervisor} ($\sim$226 pages).

\item[Part V -- Protocol Buffers Combined PDF] All proto3 schemas under
\texttt{star-proto/proto/star/v1/} (33 pages).

\item[Part VI -- Compliance Combined PDF] Python ADA-auditing engine
under \texttt{star-compliance/} ($\sim$85 pages).

\item[Part VII -- MATLAB Sources] System identification + PID design
scripts under \texttt{matlab/} (39 pages).

\item[Part VIII -- Operations] Production Grafana dashboard JSON +
rendered panel screenshots + Pi 5 cockpit-API server + systemd units
(\texttt{monitoring/} + \texttt{infra/pi5/}, 83 pages).

\item[Part IX -- Software Description Document] Capstone deliverable.

\item[Part X -- System and Software User Manual] Capstone deliverable.

\item[Part XI -- Test Report] Capstone deliverable.

\item[Part XII -- Final Demo Handout] Capstone deliverable.

\item[Part XIII -- Final Presentation] Capstone deliverable (PowerPoint
export).

\item[Part XIV -- Mechanical Drawings] Master + 9 individual parts
(Battery Box, Drivetrain Assembly, Lid L, Lid R, Motor mount, Sheet base,
Sheet Lidar, Side panel, Split rail).

\item[Part XV -- Electrical Schematics + PCB] KiCad outputs: Electrical
Design + Schematic + PCB layout.

\item[Part XVI -- Miscellaneous] Bench schematic, camera calibration,
TOM board build instructions, compliance audit sample.
\end{description}
