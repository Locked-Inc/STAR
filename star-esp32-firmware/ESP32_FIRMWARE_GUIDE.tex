\section{Project Overview}
% =============================================================================

\subsection{Purpose}

The \texttt{star-esp32-firmware} project provides real-time motor control, sensor integration, and communication with the Raspberry Pi 5 gateway for the STAR robot platform. It runs on the ESP32-S3 microcontroller using FreeRTOS.

\section{Motor Control Architecture}
% =============================================================================

\subsection{Motor Control Components}

The STAR firmware implements a modular motor control stack with clear separation of concerns:

\subsubsection{\texttt{lib/star\_motor} - Low-Level MCPWM Control}

Provides hardware abstraction for brushed DC motor control using ESP32's MCPWM peripheral.

\textbf{Key Features:}
\begin{itemize}
    \item Bidirectional PWM control (-100\% to +100\% duty cycle)
    \item Automatic dead-time insertion for H-bridge safety
    \item Configurable PWM frequency (default: 20 kHz)
    \item Optional fault input for overcurrent protection
    \item Brake and coast modes
\end{itemize}

\textbf{No bus dependency} - Direct hardware peripheral control.

\begin{lstlisting}[language=C, caption=Motor Driver Interface]
typedef struct {
    int group_id;
    uint32_t timer_resolution_hz;
    uint32_t pwm_freq_hz;
    gpio_num_t pin_pwm_a;
    gpio_num_t pin_pwm_b;
    uint32_t dead_time_ns;
    gpio_num_t fault_pin;
    bool invert_pwm;
} star_motor_config_t;

esp_err_t star_motor_init(star_motor_handle_t* handle,
                          const star_motor_config_t* config);
esp_err_t star_motor_set_duty(star_motor_handle_t* handle, float duty);
esp_err_t star_motor_stop(star_motor_handle_t* handle, bool brake);
\end{lstlisting}

\subsubsection{\texttt{lib/star\_drv8243} - DRV8243 Motor Driver Integration}

Integrates motor control with current sensing and fault detection via bus manager.

\textbf{Key Features:}
\begin{itemize}
    \item H-bridge motor control (one brushed DC motor)
    \item Current sensing via IPROPI pin (ADC)
    \item Fault detection via nFAULT pin (GPIO)
    \item Configurable current limiting
    \item PH/EN control mode (PWM + direction)
    \item PWM frequency: up to 25 kHz
\end{itemize}

\textbf{Uses bus manager} for ADC (current sensing) and GPIO (fault detection).

\subsubsection{\texttt{lib/star\_encoder} - Quadrature Encoder}

Handles position and velocity feedback using ESP32 PCNT peripheral.

\textbf{Key Features:}
\begin{itemize}
    \item Hardware-accelerated quadrature decoding
    \item Position tracking with signed 32-bit counter
    \item Velocity calculation (RPM)
    \item Configurable glitch filter
    \item Counter limits and overflow detection
\end{itemize}

\textbf{No bus dependency} - Direct PCNT peripheral access.

\subsubsection{\texttt{lib/star\_pid} - PID Controller}

Generic, stateless PID controller for closed-loop control.

\textbf{Key Features:}
\begin{itemize}
    \item Standard PID algorithm with Kp, Ki, Kd gains
    \item Configurable output limits
    \item Integral anti-windup
    \item Runtime gain tuning
    \item State reset capability
\end{itemize}

\textbf{No dependencies} - Pure algorithm, hardware-agnostic.

\begin{lstlisting}[language=C, caption=PID Controller Interface]
typedef struct {
    float kp, ki, kd;
    float output_min, output_max;
    float integral_min, integral_max;
} star_pid_config_t;

esp_err_t star_pid_init(star_pid_handle_t* handle,
                        const star_pid_config_t* config);
esp_err_t star_pid_compute(star_pid_handle_t* handle,
                           float setpoint, float measured,
                           float dt, float* output);
esp_err_t star_pid_reset(star_pid_handle_t* handle);
\end{lstlisting}

\textbf{Recommended Tuning (adjust experimentally):}
\begin{itemize}
    \item $K_p = 1.0$, $K_i = 0.5$, $K_d = 0.1$
    \item Loop rate: 1000 Hz
    \item Integral limit: $\pm$50
\end{itemize}

\subsection{Core Communication Interfaces}

\subsubsection{SPI Peripheral Driver}

The firmware implements SPI peripheral mode for communication with the Raspberry Pi 5.

\begin{itemize}
    \item \textbf{Mode:} Peripheral on SPI2 (HSPI)
    \item \textbf{Protocol:} Custom binary packet structure
    \item \textbf{Performance:} DMA is used for efficient, non-blocking transfers
\end{itemize}

\textbf{SPI Pin Mapping:}
\begin{table}[H]
\centering
\begin{tabular}{|l|l|l|}
\hline
\textbf{Signal} & \textbf{Pi5 GPIO} & \textbf{ESP32 GPIO} \\
\hline
COPI & GPIO11 & GPIO13 \\
CIPO & GPIO9 & GPIO12 \\
SCLK & GPIO11 & GPIO14 \\
CS & GPIO8 & GPIO15 \\
\hline
\end{tabular}
\end{table}

\textbf{Command Protocol:}
\begin{lstlisting}[language=C, caption=SPI Command Protocol]
// Command byte definitions
#define CMD_SET_VELOCITY    0x01  // Set wheel velocities
#define CMD_EMERGENCY_STOP  0x02  // Immediate stop
#define CMD_GET_ENCODERS    0x03  // Read encoder counts
#define CMD_GET_TELEMETRY   0x06  // Battery, temp, status

// Packet format: [CMD (1)] [LENGTH (1)] [DATA (N)] [CRC8 (1)]
typedef struct __attribute__((packed)) {
    uint8_t command;
    uint8_t length;
    uint8_t data[32];
    uint8_t crc8;
} spi_packet_t;

// Velocity command payload
typedef struct __attribute__((packed)) {
    float left_velocity;   // m/s
    float right_velocity;  // m/s
    uint32_t timestamp;    // ms since boot
} velocity_cmd_t;
\end{lstlisting}

\section{Complete Motor Control System Example}
% =============================================================================

\subsection{Closed-Loop Velocity Control}

The following example demonstrates a complete closed-loop motor control system integrating all motor control components with thermal monitoring:

\begin{lstlisting}[language=C, caption=Complete Motor Control System]
#include "star_drv8243.h"
#include "star_encoder.h"
#include "star_pid.h"
#include "star_sensor_ds18b20.h"

// === Setup Phase ===

// 1. Initialize bus manager
star_bus_manager_t bus_manager;
star_bus_manager_init(&bus_manager, "main", NULL, NULL);

// 2. Create buses
star_bus_config_t* gpio_bus = star_bus_config_create_gpio("gpio_bus");
star_bus_config_t* adc_bus = star_bus_config_create_adc(
    "adc_bus", ADC_UNIT_1, ADC_ATTEN_DB_12, ADC_BITWIDTH_12);
star_bus_config_t* onewire_bus = star_bus_config_create_onewire(
    "temp_bus", GPIO_NUM_4, false);

star_bus_manager_add_bus(&bus_manager, gpio_bus);
star_bus_manager_add_bus(&bus_manager, adc_bus);
star_bus_manager_add_bus(&bus_manager, onewire_bus);

// 3. Initialize motor driver
star_drv8243_handle_t motor;
star_drv8243_config_t motor_cfg = {
    .bus_manager = &bus_manager,
    .gpio_bus_name = "gpio_bus",
    .adc_bus_name = "adc_bus",
    .pin_pwm_ph = GPIO_NUM_25,
    .pin_pwm_en = GPIO_NUM_26,
    .pin_ipropi = ADC_CHANNEL_6,
    .pin_nfault = GPIO_NUM_35,
    .pwm_freq_hz = 20000,
    .current_limit_ma = 2000,
};
star_drv8243_init(&motor, &motor_cfg);

// 4. Initialize encoder
star_encoder_handle_t encoder;
star_encoder_config_t enc_cfg = {
    .pcnt_unit = PCNT_UNIT_0,
    .pin_a = GPIO_NUM_32,
    .pin_b = GPIO_NUM_33,
    .filter_value = 1000,
    .high_limit = 10000,
    .low_limit = -10000,
};
star_encoder_init(&encoder, &enc_cfg);

// 5. Initialize PID controller
star_pid_handle_t pid;
star_pid_config_t pid_cfg = {
    .kp = 1.0f, .ki = 0.5f, .kd = 0.1f,
    .output_min = -100.0f, .output_max = 100.0f,
    .integral_min = -50.0f, .integral_max = 50.0f,
};
star_pid_init(&pid, &pid_cfg);

// 6. Initialize temperature sensor
star_ds18b20_handle_t temp_sensor;
star_ds18b20_config_t temp_cfg = {
    .bus_manager = &bus_manager,
    .bus_name = "temp_bus",
    .resolution = k_star_ds18b20_resolution_12_bit,
    .use_rom = false,
};
star_sensor_ds18b20_init(&temp_sensor, &temp_cfg);

// === Control Loop (1000Hz) ===

float setpoint_rpm = 100.0f;
float dt = 0.001f;  // 1ms

while (1) {
    // Read encoder velocity
    float velocity_rpm;
    star_encoder_get_velocity_rpm(&encoder, dt * 1000, 500, &velocity_rpm);

    // Compute PID output
    float pid_output;
    star_pid_compute(&pid, setpoint_rpm, velocity_rpm, dt, &pid_output);

    // Apply to motor
    star_drv8243_set_speed(&motor, pid_output);

    // Monitor current and temperature
    float current_ma, temp_c;
    star_drv8243_read_current(&motor, &current_ma);
    star_sensor_ds18b20_read_temp(&temp_sensor, &temp_c);

    // Safety checks
    bool fault;
    star_drv8243_get_fault_status(&motor, &fault);
    if (fault || temp_c > 85.0f) {
        star_drv8243_stop(&motor, true);  // Emergency brake
    }

    vTaskDelay(pdMS_TO_TICKS(1));  // 1ms delay
}
\end{lstlisting}

\subsection{Architecture Benefits}

The modular design provides:

\begin{itemize}
    \item \textbf{Clear separation of concerns}: Each library has a single, well-defined purpose
    \item \textbf{Testability}: Low-level components (motor, encoder, PID) have no dependencies
    \item \textbf{Reusability}: PID and encoder libraries work with any motor driver
    \item \textbf{Safety}: Current limiting and fault detection at the integration layer
    \item \textbf{Flexibility}: Easy to swap motor drivers or add new control algorithms
\end{itemize}

\section{Build and Flash Instructions}
% =============================================================================

\subsection{Prerequisites}

\begin{lstlisting}[language=bash]
# Install PlatformIO
pip install platformio

# Install ESP-IDF (handled by PlatformIO)
pio pkg install
\end{lstlisting}

\subsection{Build Commands}

\begin{lstlisting}[language=bash]
# Build for ESP32-S3
pio run -e esp32s3

# Build for ESP32-WROOM (dev board)
pio run -e esp32_wroom

# Upload firmware
pio run -e esp32s3 --target upload

# Monitor serial output
pio device monitor -b 115200
\end{lstlisting}

\subsection{Configuration}

Edit \texttt{sdkconfig.esp32s3} for production settings:
\begin{itemize}
    \item Enable brownout detection
    \item Set CPU frequency to 240 MHz
    \item Configure flash size (16 MB)
    \item Enable PSRAM if needed
\end{itemize}
