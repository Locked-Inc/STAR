◆ async_operation_t

typedef struct async_operation async_operation_t

Async operation context.

Note
The timeout_ms field is enforced by the worker task. Operations that exceed their timeout while waiting in the queue or during execution will be completed with ESP_ERR_TIMEOUT.
The priority field is stored but FIFO ordering is used. Priority queue ordering is not currently implemented.

Blocks until the operation completes or timeout expires.

Parameters
