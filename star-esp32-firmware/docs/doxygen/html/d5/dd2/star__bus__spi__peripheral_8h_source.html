168/* --- SPI Pin Naming: COPI/CIPO (OSHWA Standard) --- */
169/* This component uses OSHWA (Open Source Hardware Association) standard SPI terminology:
170 * - COPI (Controller Out, Peripheral In): Data line where the controller sends data to the peripheral
171 * - CIPO (Controller In, Peripheral Out): Data line where the controller receives data from the peripheral
172 *
173 *
174 * Note: The ESP-IDF SPI peripheral driver (spi_slave.h) still uses legacy mosi_io_num/miso_io_num field names internally, which we map to COPI/CIPO.
175 */
