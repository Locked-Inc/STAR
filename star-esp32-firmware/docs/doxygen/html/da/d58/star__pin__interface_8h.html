Detailed Description

Abstract pin validator interface for dependency inversion.

This interface defines the contract for GPIO pin management in the STAR framework. It follows the Dependency Inversion Principle (DIP), allowing high-level components to register, unregister, and validate GPIO pins without depending on concrete pin validator implementations. Prevents pin conflicts across peripheral drivers.
