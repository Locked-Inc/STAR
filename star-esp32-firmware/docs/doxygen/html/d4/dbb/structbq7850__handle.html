Detailed Description

BQ7850 device handle.

Maintains state and error handling for BMS operations. Thread-safe: Initialization and deinitialization operations are protected by an internal mutex. Read operations do not acquire mutex (consistent with other STAR sensor drivers using const handle pointers).
