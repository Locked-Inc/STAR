Detailed Description

Abstract error handler interface for dependency inversion.

This interface defines the contract for error handling in the STAR framework. It follows the Dependency Inversion Principle (DIP), allowing high-level components to depend on this abstraction rather than concrete error handler implementations. Supports retry logic with exponential backoff for transient errors.
