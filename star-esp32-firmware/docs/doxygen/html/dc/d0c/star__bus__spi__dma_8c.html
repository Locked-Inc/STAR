Detailed Description

DMA-accelerated SPI operations implementation for high-throughput transfers.

Implements DMA-backed SPI transfer operations for maximum throughput and minimal CPU overhead when moving large data blocks. Provides zero-copy buffer management, automatic DMA-capable memory allocation, and configurable thresholds for DMA vs. polling mode. Supports full-duplex simultaneous transmit/receive with ESP32 SPI peripheral DMA channels.
