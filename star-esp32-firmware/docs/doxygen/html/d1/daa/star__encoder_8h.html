Detailed Description

Quadrature encoder driver API using ESP32 PCNT peripheral.

Quadrature encoder driver using ESP32 PCNT peripheral.

Provides an interface for tracking position and velocity using quadrature encoders with the ESP32 Pulse Counter (PCNT) peripheral. Supports edge counting, glitch filtering, velocity calculation, and configurable count limits with overflow detection.

Date
2025-12-19
Copyright
Copyright (c) 2025 STAR Project

This library provides a simple interface for reading quadrature encoders using the ESP32's Pulse Counter (PCNT) peripheral. It supports position tracking and velocity calculation for motor control applications.

Key Features:

  • Hardware-accelerated quadrature decoding
  • Position tracking with signed 32-bit counter
  • Velocity calculation
  • Configurable glitch filter
  • Counter limits and overflow detection
