Detailed Description

Brushed DC motor control API using ESP32 MCPWM peripheral.

Brushed DC motor controller using ESP32 MCPWM peripheral.

Provides an interface for controlling brushed DC motors via H-bridge drivers using the ESP32 Motor Control PWM (MCPWM) peripheral. Supports bidirectional control with configurable PWM frequency, dead-time insertion for preventing shoot-through, and fault detection.

Date
2025-12-19
Copyright
Copyright (c) 2025 STAR Project

This library provides H-bridge motor control using the ESP32's Motor Control PWM (MCPWM) peripheral. It supports bidirectional control, dead-time insertion for shoot-through protection, and optional fault detection.

Key Features:

  • Bidirectional PWM control (-100% to +100% duty cycle)
  • Automatic dead-time insertion for H-bridge safety
  • Configurable PWM frequency
  • Optional fault input for overcurrent protection
  • Brake and coast modes
