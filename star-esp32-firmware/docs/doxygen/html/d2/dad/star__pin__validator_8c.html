Detailed Description

Concrete implementation of GPIO pin conflict detection and validation.

Implements the star_pin_interface for tracking GPIO pin usage across the application. Detects conflicts where multiple components attempt to use the same pin, supports both exclusive and shared pins (e.g., I2C bus lines), and provides mutex-protected thread-safe pin registration and validation.
