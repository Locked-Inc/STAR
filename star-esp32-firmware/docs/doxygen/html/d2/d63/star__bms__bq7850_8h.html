Detailed Description

BQ7850 battery management system driver API.

TI BQ7850 Battery Management System driver.

Provides interface for Texas Instruments BQ7850 battery management IC for multi-cell lithium-ion battery packs. Supports cell voltage monitoring, temperature sensing, current measurement, and protection features via I2C/SMBus interface.

Date
2025-12-19
Copyright
Copyright (c) 2025 STAR Project

This driver provides a high-level interface to the BQ7850 multi-cell lithium-ion battery monitor and protector. It supports:

  • Up to 16 series-connected cells
  • Cell voltage monitoring
  • Temperature monitoring
  • Cell balancing
  • Protection (OV, UV, OC, OT, UT)
  • Coulomb counting
  • SMBus communication

typedef struct bq7850_handle bq7850_handle_t

BQ7850 device handle.

Maintains state and error handling for BMS operations. Thread-safe: Initialization and deinitialization operations are protected by an internal mutex. Read operations do not acquire mutex (consistent with other STAR sensor drivers using const handle pointers).
