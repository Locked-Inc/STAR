Detailed Description

ADC bus operations through the unified bus manager.

This module provides ADC analog read operations that work through the bus manager. ADC bus is used for reading analog voltages such as motor current sense lines.

Key Features:

  • Raw ADC value reading
  • Calibrated voltage reading (in millivolts)
  • Thread-safe through bus manager mutex
