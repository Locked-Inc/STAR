Detailed Description

SMBus (System Management Bus) protocol implementation over I2C.

SMBus is a subset of I2C with additional timing and protocol requirements. This module provides standard SMBus commands built on top of the star_bus I2C implementation.

SMBus Protocol Features:

  • Standardized command set
  • Packet Error Checking (PEC) support
  • Timeout requirements (25-35ms)
  • Clock stretching limits
