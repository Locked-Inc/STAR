173/* This component uses OSHWA (Open Source Hardware Association) standard SPI terminology:
174 * - COPI (Controller Out, Peripheral In): Data line where the controller sends data to the peripheral
175 * - CIPO (Controller In, Peripheral Out): Data line where the controller receives data from the peripheral
176 *
177 *
178 * Note: The ESP-IDF still uses legacy mosi_io_num/miso_io_num field names internally, which we map to COPI/CIPO.
