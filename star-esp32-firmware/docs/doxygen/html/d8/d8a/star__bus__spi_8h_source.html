162/* --- SPI Pin Naming: COPI/CIPO (OSHWA Standard) --- */
163/* This component uses OSHWA (Open Source Hardware Association) standard SPI terminology:
164 * - COPI (Controller Out, Peripheral In): Data line where the controller sends data to the peripheral
165 * - CIPO (Controller In, Peripheral Out): Data line where the controller receives data from the peripheral
166 *
167 * This modern terminology replaces the outdated master/slave language:
168 * - COPI replaces MOSI (Master Out, Slave In)
169 * - CIPO replaces MISO (Master In, Slave Out)
170 *
171 * Note: The ESP-IDF still uses mosi_io_num/miso_io_num internally, which we map to COPI/CIPO.
172 */
