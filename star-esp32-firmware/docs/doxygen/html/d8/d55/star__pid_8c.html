Detailed Description

PID controller implementation for closed-loop motor control.

Implements a stateless PID (Proportional-Integral-Derivative) controller with anti-windup, derivative filtering, and configurable output limits. Designed for embedded systems with no dynamic memory allocation and tunable gains for velocity or position control.

esp_err_t star_pid_compute ( star_pid_handle_t * handle,
float setpoint,
float measured,
float dt,
float * output )

Compute PID output for current error.

Calculates the PID control output based on the error between setpoint and measured value. This function implements the standard PID algorithm:

output = Kp*error + Ki*integral(error) + Kd*derivative(error)

The output is clamped to [output_min, output_max] and the integral term is clamped to [integral_min, integral_max] for anti-windup.

Parameters
[in]handlePointer to initialized PID handle. Must not be NULL.
[in]setpointDesired target value.
[in]measuredCurrent measured value.
[in]dtTime delta in seconds since last call.
[out]outputPointer to store PID output. Must not be NULL.
Returns
esp_err_t ESP_OK on success, error code otherwise
