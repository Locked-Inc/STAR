Detailed Description

SMBus protocol layer implementation over I2C.

Implements the System Management Bus (SMBus) protocol as a high-level abstraction over I2C. Provides standard SMBus commands including quick command, byte operations, word operations, and block transfers. Supports optional Packet Error Checking (PEC) using CRC-8 for enhanced reliability in battery management and power monitoring applications.
