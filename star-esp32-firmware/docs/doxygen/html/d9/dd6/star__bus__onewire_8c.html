Detailed Description

1-Wire protocol implementation for the bus manager

Implements Dallas/Maxim 1-Wire protocol for single-wire communication with devices like DS18B20 temperature sensors. Provides bit-banged GPIO-based timing-critical operations for reset, write, and read with support for ROM commands, device search, and parasitic power mode. Includes comprehensive CRC-8 validation for data integrity.
