Detailed Description

Quadrature encoder driver implementation using ESP32 PCNT peripheral.

Implements quadrature encoder position and velocity tracking using the ESP32 Pulse Counter (PCNT) peripheral. Supports edge counting, glitch filtering, and velocity calculation with configurable limits and overflow handling.
