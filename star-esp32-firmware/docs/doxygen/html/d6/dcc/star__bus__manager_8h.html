Detailed Description

Unified bus manager API for I2C, SPI, UART, GPIO, ADC, and 1-Wire protocols.

The bus manager provides a central registry for managing multiple bus configurations with thread-safe operations. Supports dependency injection of error handlers and pin validators for loose coupling following the Dependency Inversion Principle.

esp_err_t star_bus_manager_add_bus ( star_bus_manager_t * manager,
star_bus_config_t * config )

Add a new I2C bus/device configuration to the manager.

Adds a previously created configuration (via star_bus_config_create_i2c) to the manager's internal list. The manager takes ownership conceptually, but the configuration still needs to be destroyed eventually (typically via star_bus_manager_remove_bus or star_bus_manager_deinit). The configuration must have a unique name. This function is thread-safe.

Parameters
[in]managerPointer to the initialized bus manager. Must not be NULL.
[in]configPointer to the I2C bus configuration structure to add. Must not be NULL and must have a valid name.
Returns
esp_err_t ESP_OK on success, ESP_ERR_INVALID_ARG if manager or config is invalid, ESP_ERR_INVALID_STATE if a bus with the same name already exists or mutex error, ESP_ERR_TIMEOUT if mutex times out.

esp_err_t star_bus_manager_deinit ( star_bus_manager_t * manager)

Deinitialize the bus manager and all managed I2C bus configurations.

Iterates through all I2C bus configurations currently managed, deinitializes each one (if initialized), destroys each configuration structure (freeing memory), and finally releases the manager's resources (mutex). After this call, the manager and all its previously managed configurations are invalid.

Parameters
[in]managerPointer to the bus manager to deinitialize. Must not be NULL.
Returns
esp_err_t ESP_OK if all deinitializations and cleanup were successful, ESP_ERR_INVALID_ARG if manager is NULL, or the first error code encountered during the deinitialization/destroy process of any bus.

const char * name )

Find an I2C bus configuration by its unique name.

Searches the manager's list for a configuration matching the given name. This function is thread-safe.

Warning
The returned pointer can become invalid if another thread removes the bus. For safe access, use star_bus_manager_with_bus() instead.
Parameters
[in]managerPointer to the initialized bus manager. Can be NULL (returns NULL).
[in]nameThe unique name of the bus configuration to find. Can be NULL (returns NULL).
Returns
star_bus_config_t* Pointer to the found configuration structure, or NULL if not found or an error occurs (e.g., mutex timeout). The returned pointer is still managed by the bus manager.

Initialize an I2C bus manager instance.

Key Features:

  • Thread-safe bus management with mutex protection
  • Support for multiple bus types (I2C, SPI, GPIO, DHT22, etc.)
  • Automatic pin registration and conflict detection
  • Safe bus access via callback pattern (prevents use-after-free)

Example Usage:

Allocates resources (like a mutex) for the manager. Must be called before any other manager functions.

Parameters
[out]managerPointer to a bus manager structure to initialize. Must not be NULL.
[in]tagOptional tag string for logging associated with this manager instance. If NULL or empty, a default tag is used.
[in]error_ifaceOptional error handler interface (can be NULL).
[in]pin_ifaceOptional pin validator interface (can be NULL).
Returns
esp_err_t ESP_OK on success, ESP_ERR_INVALID_ARG if manager is NULL, ESP_ERR_NO_MEM if mutex creation fails.

esp_err_t star_bus_manager_register_all_pins ( const star_bus_manager_t * manager,
pin_registration_function_t reg_func,
void * user_ctx )

Iterates through all I2C buses/devices managed by the manager and calls a user-provided function to register each configured pin (SDA, SCL).

This allows decoupling the bus manager from a specific pin validation/tracking system. The user provides a callback function that conforms to pin_registration_function_t. This function will be called for the SDA and SCL pins associated with each I2C configuration in the manager. This function is thread-safe (acquires mutex during iteration).

Parameters
[in]managerPointer to the initialized bus manager. Must not be NULL.
[in]reg_funcThe user's pin registration callback function. Must not be NULL.
[in]user_ctxA user context pointer to be passed to the registration function.
Returns
esp_err_t ESP_OK if iteration completed (doesn't guarantee all registrations succeeded, check reg_func's return), ESP_ERR_INVALID_ARG if manager or reg_func is NULL, ESP_ERR_TIMEOUT if mutex times out. Returns the first error reported by the callback.

Remove an I2C bus configuration from the manager and destroy it.

Finds the configuration by name, removes it from the manager's list, deinitializes the associated I2C driver (if initialized), and frees the configuration structure memory (via star_bus_config_destroy). This function is thread-safe (acquires mutex initially, releases before deinit/destroy).

Parameters

[in]nameThe unique name of the bus configuration to remove and destroy. Must not be NULL.
Returns
esp_err_t ESP_OK on success, ESP_ERR_INVALID_ARG if manager or name is invalid, ESP_ERR_NOT_FOUND if bus not found, ESP_ERR_TIMEOUT if mutex times out, or an error code from the underlying deinitialization/destroy process.

◆ star_bus_manager_with_bus()

esp_err_t star_bus_manager_with_bus ( star_bus_manager_t * manager,
const char * name,
star_bus_callback_t callback,
void * user_ctx )

Safely access a bus configuration through a callback.

This function finds a bus by name and invokes the provided callback while holding the manager's mutex, preventing use-after-free issues that can occur with star_bus_manager_find_bus().

The callback is invoked with the mutex held, so operations within the callback are thread-safe with respect to bus removal.

Parameters
[in]managerPointer to the initialized bus manager. Must not be NULL.
[in]nameThe unique name of the bus configuration. Must not be NULL.
[in]callbackFunction to invoke with the found bus. Must not be NULL.
[in]user_ctxUser context passed to the callback.
Returns
esp_err_t ESP_OK if callback executed successfully, ESP_ERR_NOT_FOUND if bus not found, ESP_ERR_INVALID_ARG if arguments invalid, ESP_ERR_TIMEOUT on mutex timeout, or the error code returned by the callback.
