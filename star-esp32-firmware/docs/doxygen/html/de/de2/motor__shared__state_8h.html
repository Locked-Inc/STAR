Detailed Description

Shared state structure for motor control system.

Provides a thread-safe shared state structure for communication between motor_control_task (250Hz PID loop) and command_handler_task (ARQ message processing). All access to shared data is protected by a mutex.

The shared state contains:

  • Velocity setpoints (written by command_handler, read by motor_control)
  • Motor status (written by motor_control, read by command_handler)
  • Emergency stop flag (written by command_handler, read by motor_control)
