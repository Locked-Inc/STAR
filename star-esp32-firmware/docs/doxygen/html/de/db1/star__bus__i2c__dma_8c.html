Detailed Description

I2C DMA transfer implementation for high-throughput operations.

Implements DMA-based I2C transfers for efficient large data transfers without CPU involvement. Reduces interrupt overhead and improves system responsiveness.

Read data from I2C device using DMA.

Performs a DMA-accelerated read from an I2C device. Automatically falls back to non-DMA operation if transfer is too small or DMA is not available.

Parameters
[in]managerPointer to initialized bus manager
[in]bus_nameName of I2C bus
[out]dataPointer to receive buffer (must be DMA-capable for large transfers)
[in]lengthNumber of bytes to read
[in]commandOptional command byte (0xFF for no command)
[in]callbackOptional completion callback (NULL for blocking)
[in]contextUser context for callback
Returns
ESP_OK on success, error code otherwise
Note
If callback is NULL, operation is blocking
If callback is provided, operation is asynchronous
Data buffer must remain valid until callback is called
