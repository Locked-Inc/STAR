# STAR RX72N Firmware - CMake Build System

Portable CMake build system for the STAR RX72N motor controller firmware.

## Features

- ✅ **Truly portable** - Works on WSL, Linux, macOS, Dev Containers, CI/CD
- ✅ **C23 standard** with GNU extensions
- ✅ **Strict warnings** - `-Wall -Wextra -Werror`
- ✅ **Cross-platform** - No hardcoded Windows paths
- ✅ **IDE support** - Generates `compile_commands.json` for clangd/IntelliSense

## Prerequisites

**GNURX Toolchain** (rx-elf-gcc) must be installed and in PATH:

```bash
# Install location (one of):
# - $HOME/gnurx/bin
# - /opt/gnurx/bin
# - /usr/local/gnurx/bin

# Add to PATH (or add to ~/.bashrc):
export PATH="$HOME/gnurx/bin:$PATH"

# Verify:
rx-elf-gcc --version
```

## Quick Start

### Build (Debug Mode)

```bash
./build.sh
```

### Build (Release Mode)

```bash
./build.sh release
```

### Clean Build

```bash
./build.sh clean
```

### Verbose Output

```bash
./build.sh -v
```

## Manual CMake Usage

If you prefer to use CMake directly:

```bash
# Configure
mkdir build && cd build
cmake -DCMAKE_TOOLCHAIN_FILE=../cmake/toolchain-rx72n.cmake \
      -DCMAKE_BUILD_TYPE=Debug \
      ..

# Build
cmake --build . -j$(nproc)

# Output files
ls *.elf *.mot *.map
```

## Build Artifacts

After a successful build:

- `star-rx72n-firmware.elf` - Executable (for debugging/flashing)
- `star-rx72n-firmware.mot` - Motorola S-Record (for production flash)
- `star-rx72n-firmware.map` - Linker map file
- `compile_commands.json` - For IDE code completion

## Dev Container Support

The CMake build works seamlessly in the dev container:

1. Container starts → GNURX toolchain mounted from host
2. Run `./build.sh` → Build succeeds
3. No path conversions needed!

## Comparison: CMake vs e² Studio Makefile

| Feature | CMake | e² Studio Makefile |
|---------|-------|-------------------|
| **Portability** | ✅ WSL, Linux, macOS, containers | ❌ Windows/WSL only |
| **Path handling** | ✅ Relative paths | ❌ Absolute Windows paths |
| **Maintenance** | ✅ One CMakeLists.txt | ❌ Regenerated by IDE |
| **CI/CD** | ✅ Works everywhere | ❌ Requires path hacks |
| **IDE support** | ✅ compile_commands.json | ⚠️ Eclipse-specific |

## Troubleshooting

**Error: "rx-elf-gcc not found in PATH"**

```bash
# Find your GNURX installation:
find ~ -name "rx-elf-gcc" 2>/dev/null

# Add to PATH:
export PATH="/path/to/gnurx/bin:$PATH"
```

**Error: "Linker script not found"**

Ensure `src/linker_script.ld` exists. This file should be in your repository.

**Build warnings about "Clock skew detected"**

This is harmless - it's due to WSL/Windows time sync differences. The build will still succeed.

## Configuration

### Changing Build Flags

Edit `cmake/toolchain-rx72n.cmake` to modify:
- CPU flags (`-mcpu`, `-misa`, etc.)
- Optimization level
- Warning flags

### Adding Source Files

CMake automatically discovers `.c` and `.S` files in:
- `src/` (except `smc_gen/`)
- `src/boot/`
- `src/tasks/`
- `src/shared/`
- `src/rtos_config/`
- `libs/` (all custom libraries)

No manual updates needed when adding new files!

## Integration with e² Studio

You can use **both** build systems:

- **e² studio** - For GUI debugging, flashing hardware
- **CMake** - For CLI builds, CI/CD, dev containers

The CMakeLists.txt is maintained separately and won't be overwritten by e² studio.
